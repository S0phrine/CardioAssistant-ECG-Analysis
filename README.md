# CardioAssistant-ECG-Analysis
🇵🇱 Projekt akademicki zrealizowany w ramach pracy inżynierskiej, dotyczący analizy sygnałów EKG i klasyfikacji arytmii. Nie jest przeznaczony do zastosowań klinicznych. 🇬🇧 Academic project developed as part of an engineering thesis, focused on ECG signal analysis and arrhythmia classification. Not intended for clinical use.
